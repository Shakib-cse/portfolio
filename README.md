# 💼 Developer Portfolio - Shakib

A professional and responsive developer portfolio built with **React**, **Tailwind CSS**. This portfolio highlights my skills, projects, education, and experience as a Front-End Developer and MERN stack enthusiast.


---

## 🚀 Features

- ⚡ Beautiful Hero Section with Social Links and Resume Download
- 🧠 About Me & Skills Section with Animated Scroll (AOS)
- 🎓 Education Section
- 💻 Dynamic Projects Section with detailed project pages
- 📞 Contact Section with Email and WhatsApp
- 🌐 Smooth scroll and responsive design
- 🔐 Firebase Auth (Login system for other app integration)
- 🎨 Modern UI using Tailwind CSS and DaisyUI
